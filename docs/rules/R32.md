# R32

**Owner-authorised rounds are the only way source is written**

**Status:** owner-stated 2026-11-24  
**Evidence:** The relay forbids editing project files, so a named round is the only route into `src/`; two agents stalled for hours on that wording. The owner names the round and its file list, only those files may be written, the round appends its file list, its before/after numbers and how to revert, and dated backups stay inside `PS4Dev/` under `_scratch/backups/` with their hashes in the relay. A round with no file list is not authorised.
