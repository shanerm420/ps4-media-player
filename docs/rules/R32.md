# R32

**Every build detects the machine by measurement and spends what it finds; base PS4 is the floor and Pro headroom is used automatically** — owner, 2026-11-25: "this should work on all PS4 models with options for PS4 Pro models that seamlessly work as they are intended". Base, Slim and Pro run the same code: the ladder probes a step it has never measured on this console and keeps it only if it fits, so a Pro settles at full resolution and a base PS4 settles at whatever holds its budget. `[quality] tier` (0 auto, 1 base, 2 pro) states the machine instead of measuring it; tier 2 tightens the budgets to 16.6/25.0 ms. No model API is trusted, because none is confirmed here.
