# R16

**`u_blurRadius` is a `vec2` (`0x8B50`), not a vec4** — set it with `glUniform2f`; a wrong type is rejected with `illegal to set uniform data with different types` and silently leaves the kernel at defaults

**Status:** measured (console, 2026-11-24)  
**Evidence:** `[PIG]E-glUniform4f:8900` + `CHK pass-blur glerr=0x0502` in `gpu-bloom97.log`; corrects the earlier vec4 note in §4
