# R38

**A pointer resolves in one of three declared namespaces**

**Status:** measured 2026-11-24 (read from the tree and the publisher)  
**Evidence:** A backticked path resolves in the working tree, in the publish output (`tools/publish-docs.py` generates `docs/README.md` and `CHECKSUMS.txt`), or on the console under `/data/`. It is dead only when it resolves in none of the three. R35 runs in the first two and names the namespace it resolved in, so a generated page is not a broken pointer and a green markdown link check is not coverage of a backticked span.
