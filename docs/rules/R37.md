# R37

**Each agent verifies independently, and no agent's report is evidence for the other**

**Status:** owner-stated 2026-11-24  
**Evidence:** Two agents share one laptop and one tree. A claim confirmed by its own author is not a verification, so each side checks the tree directly - hash, mtime, rule count, the checker's own output - and records its own result with the hash it saw. A peer's summary is a lead to check, not a fact. Disagreement is settled by a hash, never by repetition or seniority; where two readings persist, both are recorded and the test that separates them is named.
