# R36

**Every measured rule names the machine it was measured on**

**Status:** owner-stated 2026-11-24  
**Evidence:** The console is a PS4 Pro on 12.52 with GoldHEN v2.4b18.14, and today that lives only in prose. A measured rule carries the firmware and loader version beside the number, so a reader on another version re-verifies instead of inheriting a figure that may not apply. Unmeasured rules say `unmeasured` rather than borrowing a number from a neighbouring row.
